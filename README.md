# FM Player Score

一个用于Football Manager (FM)球员评分的桌面工具项目。

## 项目简介

本项目实现了一个根据球员属性计算评分的工具，基于三段式阶梯公式对FM游戏中的球员进行打分。

## 功能特性

- 支持39项球员属性的评分计算
- 使用变区间阶梯公式（标准属性使用1-6/6-12/12-20区间，特殊属性使用1-6/6-10/10-20区间）
- 支持CSV/Excel数据导入
- 提供Web界面Demo

## 评分公式

### 标准公式（属性值1-20）

对于大部分属性：
- 属性值 ≤ 6: (属性值 - 1) × 权重1
- 6 < 属性值 ≤ 12: 5 × 权重1 + (属性值 - 6) × 权重2
- 属性值 > 12: 5 × 权重1 + 6 × 权重2 + (属性值 - 12) × 权重3

### 特殊公式

对于才华、投入、领导力、侵略性、意志、勇敢、稳定、大赛发挥、抗压等属性：
- 属性值 ≤ 6: (属性值 - 1) × 权重1
- 6 < 属性值 ≤ 10: 5 × 权重1 + (属性值 - 4) × 权重2_special
- 属性值 > 10: 5 × 权重1 + 4 × 权重2_special + (属性值 - 10) × 权重3_special
